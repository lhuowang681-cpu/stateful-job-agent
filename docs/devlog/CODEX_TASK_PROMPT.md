# 发给 Codex 的阶段任务补充指令（复制使用）

从现在开始，你可以自主完成本阶段全部开发，不需要每一步都等待我决定或解释，也不要为了写文档牺牲开发进度。但请严格遵守仓库根目录 `AGENTS.md` 的学习留痕协议。

具体要求：

1. 阶段开始时，更新 `docs/devlog/INDEX.md`，记录目标、验收标准和 Git 基线。
2. 每完成一个可独立工作的功能，就将“问题 → 解决方案及替代方案 → 核心代码路径/函数 → 实际调用链 → 测试命令和结果 → 局限”简要写入本阶段的 `PHASE-XX-*.md`。不要等整个阶段做完才写。记录真实技术决策，不需要输出任何内部隐含推理。
3. 阶段结束后补齐阶段报告，更新 `ARCHITECTURE_MAP.md` 和 `DECISIONS.md`，确保后续学习者仅靠这些文件，就可以按顺序找到需要阅读的代码、运行 Demo、复现验证。
4. 写 5 道真实面试官可能深入追问的问题及回答要点，重点问“为什么这样设计、有何取舍、如何实现、实测效果、失败怎么办”。
5. **真实性是硬约束：** 所有函数名/文件路径必须存在；未运行的测试写“未运行”；Mock 不能说成真实端到端；无对照实验就不要编造提升率。敏感材料脱敏。
6. 最终对话汇报优先提供：完成哪些功能、哪些验证通过、哪些未完成、这阶段学习先看哪 3～5 个 `文件::函数`、阶段报告路径。不需要粘贴几千行解释。
